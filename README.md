# 💻 Laptop Market Analysis Dashboard

##  Project Overview
The Laptop Market Analysis Dashboard is developed using Microsoft Power BI to analyze laptop market trends. The dashboard provides interactive visualizations to compare laptop brands, prices, CPU configurations, RAM options, operating systems, and display sizes.

##  Objectives
- Analyze laptop prices across different brands.
- Compare CPU configurations and average prices.
- Understand RAM distribution.
- Visualize operating system usage.
- Study the relationship between display size and laptop price.

##  Tools Used
- Microsoft Power BI
- DAX (Data Analysis Expressions)
- Power Query
- Microsoft Excel / CSV Dataset

##  Dataset
The dataset contains **893 laptop records** with the following attributes:

- Brand
- Laptop Name
- Price
- CPU
- Processor
- RAM
- RAM Type
- ROM
- ROM Type
- GPU
- Display Size
- Resolution
- Operating System
- Warranty
- Specification Rating

##  Dashboard Features

### KPI Cards
- Total Laptops
- Total Brands
- Average Price

### Visualizations
- Average Price by Brand (Bar Chart)
- RAM Distribution (Donut Chart)
- Operating System Distribution (Line Chart)
- Average Price by Brand (Waterfall Chart)
- Average Price by Display Size (Line Chart)
- Average Price by CPU (Horizontal Bar Chart)
- Average Price Gauge

##  Key Insights
- Compare average laptop prices across brands.
- Identify the most common RAM configuration.
- Analyze the operating systems available.
- Understand how display size affects price.
- Compare CPU core configurations with average price.

##  Future Improvements
- Add filters for GPU and Processor.
- Integrate live online datasets.
- Include sales and customer ratings.
- Add forecasting using Power BI AI visuals.
